# 柳汊 · 早渡

架空江南小镇的俯视像素经营试玩版。以 Godot 4.5.1 和 GDScript 制作，使用独立 Git 仓库。

## 游玩

Windows 试玩包中双击 Liucha.exe，同目录需有 Liucha.pck。源码目录运行 Play.cmd，或以 Godot 4.5.1 打开 project.godot 后按 F6（当前场景）或 F5。启动器支持 PATH 中的 godot.exe，以及 LIUCHA_GODOT 指定的引擎。

### 从春畦出门

单击空地按直线前往，遇到障碍自动绕行。右键只走路，方向键 / WASD 可自由步行。左键点物件会在进入操作范围时停下；也可以自己走到床沿、井边、摊前或居民身旁按 E。多个目标在身旁时，Tab 切换提示。沿小院右侧路牌进镇，再向东可到芦湾，向西原路返回。农舍左边是床，右边是灶与竹篮。J 翻开托运簿，B 打开行囊，Esc 返回或收起工具。

底部的五件工具支持点击和数字键 1–5。空手采收；短锄理去枯枝、开新畦；种袋向空畦播种；水壶润土；竹竿在芦湾钓台抛线。浮子下沉时点击水面或按 E 收竿。背篓里可换种、吃东西。水壶在院井边装满。每日体力有限，睡觉后恢复，晚上十点收工。雨天作物会自己得水。

### 经营与往来

- 院内草地由 13×4 格构成。新开局从空院和两份木料开始。选短锄，点自己选的草地即可开畦；有枯枝的格子先清理。用「营造」选格搭箱、平整空畦或拆收箱板。箱中货物共用一份晚船货单。旧存档的田和箱按原位置接续，原门前的箱子也可拆走重搭。
- 每季十四天，菜铺从早七点经营到傍晚六点。蚕豆宜春秋，菱角宜夏，芋头宜秋，萝卜四季可种。错季时已经种下的菜会继续生长。镇街上的街坊托单每日一换，按单送足实物会收到现钱和情分。每位居民每日可收一份礼；阿禾熟悉你后会多给一粒种子。
- 芦湾有每日再生的马兰头与河鲫。把两样带回灶台可煮汤，补充体力。陆木匠可扩充水壶，也可以谈定收取木料修船。船修好后，双日上午有直达芦湾钓台的早渡；阿禾的早市每尾鲜鱼现付八文。
- 账房默认每晚全卖。作物、鱼获、野菜和木料都可单独记托运约定。先看当晚的试算，再确认规则；与木匠商定的送木约定在船修好后自动结束。日常经营无需通过对话完成。

场景采用柳汊原创的高分辨率水乡像素图，默认窗口 1600×900。各地点单独定义活动地带、固定设施、路口、人物日程和地图交互，点击移动经过寻路网格。

## 模型和存档

在「设置 → 全镇默认」选择服务商和模型 ID，也可给账房先生、阿禾、陆木匠、周叔单独配置。角色默认沿用全镇设置。连接测试按角色验证居民台词或账房拟约；全镇默认会测试两种回复。

预设沿用《河湾》和《玄武门前》的模型目录，支持 Chat Completions 和 Anthropic Messages，并提供自定义地址和模型 ID。河湾云 Qwen 7B 和 14B 分别使用本机 18760 和 18761 的转发及已有云凭证。模型可用性取决于接口供应商和账户权限。

密钥按完整接口地址区分。勾选记住后使用当前 Windows 用户的 DPAPI 加密保存；未勾选时只在本次游戏使用。在 Windows 上，档案和模型配置默认位于 %APPDATA%\Liucha。日常经营、项目式托运单和默认居民日程可离线使用。

## 开发验收

在 Godot 导入资源后运行：

```
godot --headless --max-fps 60 --path . --script res://tests/play_week.gd
godot --headless --max-fps 60 --path . --script res://tests/controls.gd
godot --headless --max-fps 60 --path . --script res://tests/play_life.gd -- --live
godot --headless --max-fps 60 --path . --script res://tests/play_week.gd -- --live
godot --headless --max-fps 60 --path . --script res://tests/models.gd -- --live
```

带 --live 的用例会实际访问模型。模型设置用例使用临时配置，验证两种协议、Windows 密钥持久化和角色设置，并在真实测试中使用河湾云 7B 和 14B。测试使用单独的临时游戏存档。Windows 导出预设为 Windows Desktop。安装 Godot 4.5.1 Windows 导出模板后可直接导出。

村景底图由 imagegen 为本项目生成，角色、作物、船、天气与音效在引擎中绘制或合成。
